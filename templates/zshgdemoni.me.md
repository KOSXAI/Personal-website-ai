# Gdemoni Personal World — 参考模板 #012

> 网址：https://zshgdemoni.me

## 基本信息

- 名称：Gdemoni Personal World
- 技术栈：Vite + React + Vanilla JavaScript + GSAP + Motion，多页面静态站
- 语言：zh-CN / English
- 定位：**软件工程学生 × AI Builder 的互动数字花园** —— 用持续生长的花园叙事，集中展示个人介绍、真实项目、工具能力与成长经历
- GitHub：[gdemoni/Gdemoni-personal](https://github.com/gdemoni/Gdemoni-personal)
- 社交：X [@Gdemonizsh](https://x.com/Gdemonizsh)

## 首页结构

1. **Garden Entrance**：用可撕门票作为进入网站的第一步，在首屏直接建立「个人小世界」的叙事
2. **Garden Profile**：介绍 Gdemoni 的学生身份、当前方向、兴趣与持续更新网站的初衷
3. **Project Greenhouse**：集中展示 Askio、EduAvatar、Travel Agent、Gdemoni Mail 等真实项目，并提供项目详情与外部入口
4. **Tool Shed**：按开发、设计和 AI 工具整理正在使用或学习的能力
5. **Growing**：用成长路径记录教育背景、实习经历与现阶段投入方向
6. **Mailbox / Coming Soon**：汇总邮件、GitHub、X、微信与简历入口，并为后续博客和新作品保留空间

## 可作为模板吸收的设计要点

- **完整的世界观入口**：门票不是装饰，而是进入花园的主要交互；撕票动作把普通页面跳转变成一次有记忆点的访问仪式。
- **统一的花园隐喻**：园丁档案、项目温室、工具棚、成长小径和花园信箱共同组成导航体系，让分散的个人信息保持同一种表达语言。
- **作品与成长并重**：既展示可核对的真实项目和技术细节，也保留学生阶段的学习过程与探索状态，避免把个人站写成静态简历。
- **可探索的细节反馈**：项目详情、花园集章、植物动效、门票导航与联系方式预览让访客在浏览过程中持续获得反馈。
- **双语与减少动效支持**：核心内容支持中文 / English 切换，并为偏好减少动效的用户提供回退体验。
- **内容集中维护**：项目数据与中英文词典集中组织，适合作为学生开发者或 AI Builder 的开源个人站起点。

## 适用人群

正在积累作品与经历的学生开发者、AI Builder 和独立开发者——希望把真实项目、学习路径、工具能力与个人兴趣放进同一个持续生长的网站，并通过鲜明互动建立个人辨识度。
