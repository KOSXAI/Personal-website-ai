# chendahuang.com — 参考模板 #001

> 来源：用户本人的个人网站，作为模板库（获客/SEO 资产）的第一份参考样板。

## 基本信息

- 名称：陈大黄（作品与内容陈列站）
- 技术栈：Nuxt 3（Vue），Nuxt UI / Tailwind，Cloudflare（Workers/Pages），生成式 SSR
- 语言：zh-CN，暗色为主
- 定位：**独立开发者的作品与内容陈列站** —— 项目 + 博客 + Playbook + 技能，公开记录探索过程

## 首页结构

1. **Hero 头部**：姓名大标题 + 一句话人设（"洞察达人、段子手｜前 AI 产品经理｜独立开发者｜…"）
2. **最近在做的项目**（卡片网格）：FlareMo、Sub-Store Cloudflare、God-Museum、AI Chronicle，每个卡片有名字 + 一句话简介
3. **精华帖子**：置顶精选内容
4. **最新文章**：博客文章列表
5. **About 简介 + 社交链接**：X（Twitter）、GitHub、RSS
6. **页脚**：邮箱、开源链接

## 内容板块（导航）

- `/` 首页
- `/projects` 项目
- `/blog` 博客
- `/highlights` 精华帖子（内容最丰富，28 万字节）
- `/playbooks` 操作手册
- `/skills` 技能
- `/search` 搜索
- `/rss.xml` RSS 订阅

## 可作为模板吸收的设计要点

- **人设一句话**：在 Hero 直接亮出身份标签，让访客 1 秒了解这个人
- **项目卡片**：名字 + 一句简介 + 外链，克制、好扫读
- **多内容类型**：项目 / 博客 / 手册 / 技能 / 精华，分层陈列
- **作品即公开记录**：把探索过程本身当作内容，天然吸引同类人
- **RSS + 搜索**：老牌但实用的内容触达与检索
- **暗色科技感**：贴合 AI 开发者的审美

## 用途

作为「AI 个人主页 / 数字名片」模板库的基准之一 —— 面向独立开发者、内容创作者这类人群，展示"作品 + 内容 + 人设"三合一的布局方式。
