## 里程碑路线图

里程碑是**验证关卡，不是任务清单**——每一关都有一道门，过了才能进下一关；先验证"有没有人付钱"，最后才碰"怎么规模化"。

1. **M1 卖出去（付费验证）** — 不靠 AI、不靠流水线，纯手工交付，拿到前 3~5 个付费客户。*门：≥3 人真金白银付钱，且能说清谁付的、付了多少、买的是什么。*
2. **M2 能复制（SOP + 定价）** — 把手工建站固化成固定流程/报价/交付时长。*门：能力相当的人照 SOP 能在固定时长内交付一致质量；单客毛利 > 0。*
3. **M3 能自动化（工具化）** — 用 AI/脚本替换 SOP 里的重复环节，模板库在此变成产品原料。*门：交付时间趋近 0，或非技术者照着工具也能交付。*
4. **M4 能自运转（SaaS）** — 自助下单、自动发货、订阅/一次性收费跑通。*门：陌生客户全程不联系你也能拿到满意网站。*
5. **M5 能放大（增长 + 分润）** — 规模化获客、合作分润、按需迭代。*门：获客成本 < 客户终身价值，且至少一条获客渠道可复制。*
