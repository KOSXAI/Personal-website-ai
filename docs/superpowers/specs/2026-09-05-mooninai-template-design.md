# MoonInAI 参考模板 #009 收录设计

## 目标

把 [MoonInAI](https://mooninai.top/) 作为模板库第 009 个公开参考案例收录，帮助访客理解「AI 系统顾问 / Build in Public」个人站如何呈现专业服务、方法与可验证作品。

## 范围

- 添加首页截图，分别存放在 `templates/` 和 `site/assets/`。
- 新增 `templates/mooninai.top.md`，只记录主页上可长期核对的定位、结构、设计要点和适用人群。
- 在 `README.zh.md` 与 `README.md` 追加双语模板条目。
- 在 `site/index.html` 追加一张展示卡片，直接链接至 `https://mooninai.top/`。

## 内容原则

- 使用公开主页所述的定位：以 AI 改造真实业务，并用系统拆解学习、副业和增长。
- 突出页面可复用的结构：月球 Hero、公开作品、按场景组织的服务、四步合作过程与联系入口。
- 描述月球探索视觉、深色基底与荧光绿点缀如何服务于品牌识别和信息组织。
- 不把会变化的 Star、Fork、服务状态或具体统计数字写入项目文档和展示页。
- 不推测站长身份、未公开技术栈或站外社交资料。

## 验收与校验

- 两份 README 中的图片和文档相对路径有效，主页链接为 HTTPS。
- 展示页卡片使用现有 `.card` 结构、图片资源路径和外链安全属性。
- 检查 Markdown 链接、图片文件和 HTML 相邻结构；若仓库没有自动化测试，则以静态检查完成验证。

## 非目标

- 不改动 MoonInAI 网站本身。
- 不新增产品功能、构建工具或页面样式。
