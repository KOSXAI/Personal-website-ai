# Personal-website-ai

AI 时代，属于你的数字名片站。一张数字名片，就是你的完整个人官网。交给信息，收获你的 AI 个人主页。

## 项目名字候选

以下为待选名字，最终二选一定案：

1. **MeSite** —— 我的站点，直白好记，用户一眼懂是个人专属网站，发音顺口。
2. **AutoMePage** —— 自动生成我的主页，突出自动化、零操作。
3. **NexMe** —— 新一代个人数字主页，简约高级，适配 AI 科技感。
4. **HostMe** —— 点明核心：托管 + 建站全包，不用用户管部署。
5. **BuildMeAI** —— AI 帮你搭建个人站点，功能直白。

## 项目初心

AI 时代，让每个人都能拥有一张属于自己的数字名片 —— 一个完整、美观、免维护的个人官网，由 AI 自动搭建。

### 里程碑 2：流水线 SOP 化
把搭建网站、购买域名、部署这些事情 SOP 化，组成一个**半自动的流水线流程**。

### 里程碑 3：获客盈利
开始获客、推销、开始盈利成交，然后讨论**合作分润**方式。

### 里程碑 4：SaaS 化
把这一套东西形成一个 **SaaS**：全自动发货、全自动运行、全自动收钱。

### 里程碑 5：规模化推广
加速推广、持续获客，根据个性化需求**持续迭代**。
